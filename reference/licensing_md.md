# Licensing Markdown

A string of markdown code indicating the licensing of the code and
documentation

## Usage

``` r
licensing_md()
```

## Examples

``` r
licensing_md()
#> [1] "## Licensing\n  Copyright 2022-2023 Integrated Ecological Research and Poisson Consulting Ltd.\\\n  Copyright 2024 Province of Alberta\\\n  Copyright (c) His Majesty the King in Right of Canada as represented by the Minister of the Environment 2025\\\n\n  The documentation is released under the\n  [CC BY 4.0 License](https://creativecommons.org/licenses/by/4.0/)\n\n  The code is released under the\n  [Apache License 2.0](https://www.apache.org/licenses/LICENSE-2.0)\n"
```
